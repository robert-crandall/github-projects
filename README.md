# GitHub Projects

A greenfield app for GitHub notifications, local commitments, and a stable working context. The previous implementation has been removed.

## Start here

1. Read [PRODUCT.md](PRODUCT.md) for the approved behavior and acceptance scenarios.
2. Read [the prototype brief](docs/prototype-prompt.md) for the first build: a clickable browser prototype with synthetic data.
3. Use [DESIGN.md](DESIGN.md) for composition and [theme.md](docs/theme.md) for the Fox and GitHub theme references.

The default theme and exact palette remain open. Dusk is not a fallback.

This repository currently contains requirements, not a runnable application. There is no backend, database migration, or installation step yet.
